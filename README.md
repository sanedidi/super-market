# super-market

Платформа для локальных магазинов и сетей: онлайн-заказы с доставкой силами магазина, учёт (закупки, склад, финансы), POS и панель супер-админа.

## Структура

- `backend/` — Go, модульный монолит (API + worker)
- `apps/client/` — Flutter, приложение покупателя
- `apps/pos/` — Flutter, POS для планшета, телефона и десктопа
- `apps/web/` — Next.js, панель магазина и супер-админ
- `deploy/` — docker-compose, nginx
- `docs/` — решения и API
