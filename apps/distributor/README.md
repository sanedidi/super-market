# SM Дистрибьютор (apps/distributor)

Приложение для дистрибьюторов (Figma «SM Дистрибьютор · приложение», секции Д1–Д14).
Только мобильное — веб-панели у дистрибьютора нет.

- Главная (Д1): заказы от магазинов, «Магазинам не хватает», склад за сегодня.
- Магазины (Д2–Д3, Д11–Д13): карта и список — кому чего не хватает; неподключённые
  магазины в 15 км от склада; «Договориться» — код на месте (QR + 4 цифры, 10 минут) или запрос.
- Заказы (Д4–Д5): новый → принят → собран → доставлен; «Доставлен» проводит расход,
  у магазина появляется черновик прихода.
- Склад (Д6–Д8): приход от производителя, расход магазину, инвентаризация, списание.
- Ещё: «Начало работы» — ввод товаров теми же экранами, что в «SM Магазин»
  (пакет `sm_store` подключён как зависимость), условия для магазинов, запросы.

Вход — логин и пароль от супер-админа (сеть вида «Дистрибьютор» в панели супер-админа),
токен приложения магазина: работают те же маршруты `/store/*` плюс `/store/supply/*`.
Аккаунт магазина в этом приложении не открывается («Войдите в SM Магазин»).

## Запуск

```sh
cd apps/distributor
flutter create --platforms=android,ios --org uz.supermarket --project-name sm_distributor .
rm -f test/widget_test.dart
bash branding/apply.sh
flutter pub get
flutter run --dart-define=API_URL=http://localhost:8080/api/v1
```

Push-уведомлений пока нет: нужен отдельный проект приложения в Firebase (как у «SM Магазин»).
Сервер уже кладёт уведомления дистрибьютору (новый заказ, запрос магазина, расхождение при приёме).
