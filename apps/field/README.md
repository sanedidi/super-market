# SM Продажник

Приложение продажников Super Market (Figma «SM Продажник · Обход с записью пути», П1–П7):
обход районов с записью пути, карта обойдённых улиц, сетки и «белых зон», отметки магазинов
(подключить / отказ / закрыт / прийти позже / уже с Super Market) и заявки на подключение.

- Вход — логин и пароль от супер-админа (панель → «Продажники»).
- Путь пишется только между «Начать обход» и «Закончить»: Android — служба с уведомлением
  «Идёт обход», iPhone — фоновый режим location. Точки копятся в телефоне и уходят на сервер
  пачкой раз в 30 секунд; без интернета ждут.
- API — раздел «SM Продажник» в docs/api.md (`/field/*`).

Запуск: `flutter run --dart-define=API_URL=http://<api>/api/v1`.
Папки платформ создаются при сборке (`flutter create … && bash branding/apply.sh`):
APK — CI по метке `[build: field]`, iOS — `bash apps/field/branding/build_ios.sh` на Mac.
