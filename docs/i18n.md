# Языки: узбекский и русский

Все приложения, панель магазина, бэкенд и лендинг — на двух языках:
**узбекский (латиница) — по умолчанию**, русский — по выбору. Панель
супер-админа (`web/admin`) остаётся только на русском, но в её формах есть
узбекские поля для данных (категории, единицы, товары).

## Как устроено

| Где | Как писать строку | Язык берётся из |
|---|---|---|
| Flutter (`apps/*`) | `tr('Сохранить', 'Saqlash')` из `sm_core` | `Lang.instance` (выбор на устройстве, по умолчанию `uz`) |
| Веб (`web/store`, `web/shared`) | `tr('Сохранить', 'Saqlash')` из `@sm/shared` | `localStorage.sm_lang`, по умолчанию `uz`; в сборке супер-админа — всегда `ru` |
| Бэкенд, ошибки | `apperr.Validation("…").Uz("…")` | `Accept-Language` запроса |
| Бэкенд, прочие тексты | `i18n.T(ctx, "…", "…")`, `i18n.Text{RU, UZ}` | контекст запроса или `i18n.WithLang(ctx, user.language)` |
| Бэкенд, данные | `loc(p.name, p.name_uz)` в SQL | `app.lang` соединения — ставит пул по контексту |

- Каждый запрос приложений и панели идёт с `Accept-Language: uz|ru`.
  Запрос **без** заголовка (старые версии приложений) получает русский — как раньше.
- Язык сотрудника/курьера для уведомлений — `users.language`: обновляется при
  входе и обновлении токена, а также `PUT /me/language {"language"}`.
  У покупателя — `customers.language` (`PATCH /client/me`).
- Переводимые данные: `categories.name_uz`, `colors.name_uz`,
  `units.name_uz`, `units.short_name_uz`, `products.name_uz`,
  `products.description_uz`. Колонки без суффикса — русские. Пустой перевод —
  показывается русский.
- В ответах API `name` (и т.п.) уже на языке запроса. В ответах для
  редактирования дополнительно — сырые `name_ru` и `name_uz`.
- При записи: `name` — по-русски, `name_uz` — по-узбекски; если пришёл только
  `name_uz`, он же пишется и в `name`.
- Кнопка «Перевести автоматически» — `POST /translate {"texts": [...], "to": "uz"|"ru"}`
  → `{"texts": [...]}`. Перевод делает ИИ-сервис, который настраивает
  супер-админ; расход — в `ai_usage` с `kind = 'translate'`.
  Flutter: `TranslateButton(api:, source:, target:, to:)`;
  веб: `<FormTranslate form from into to />` или `<TranslateButton>`.

- Ошибки, которые строят пакеты сами: `db.Remove(..., what i18n.Text, ...)`,
  `ai.ErrService{Msg, MsgUz}`, `i18n.Error` для текстов внутри «неверный JSON: …».
- Уведомления (Telegram, push) уходят на языке получателя: сотрудникам и
  курьерам — `users.language`, покупателям — `customers.language`; супер-админам —
  по-русски. Бот отвечает на языке интерфейса Telegram (`language_code`).
- Документы сайта (`/privacy`, `/offer`, `/offer/stores`, `/courier-terms`,
  `/delete-account`) по умолчанию узбекские, русские — с суффиксом `/ru`.
  Бэкенд отдаёт ссылки уже на языке запроса (`profile.DocURL`), приложения
  открывают их через `docUrl(url)` из `sm_core`.
- Касса: каталог хранит `name` (на языке кассы) и `name_ru`/`name_uz`; в
  фискальный модуль и ОФД всегда уходит русское название (`fiscalName`,
  `fiscal_name` в строках продажи) — как до появления языков. После смены
  языка касса один раз загружает каталог целиком.
- Карта Яндекса в приложении покупателя берёт язык из сохранённого выбора
  при запуске (MainActivity.kt / AppDelegate.swift) — меняется со следующего запуска.
- Супер-админ: в справочниках и товарах — поля «(узб.)» с кнопкой перевода,
  раздел «Переводы» — массовый автоперевод недостающего
  (`GET /admin/i18n/stats`, `POST /admin/i18n/translate-missing`).

## Тесты

- Бэкенд: запросы в тестах без `Accept-Language` → русский; узбекский —
  `a.doLang("uz", ...)`. В `freshDB` тестовая база создаёт пользователей с
  языком `ru`, как было до 0039 (старые тесты ждут русских уведомлений).
- Flutter: проверки в тестах на русском — в начале `main()`
  `setUpAll(() => Lang.instance.debugUse(Lang.ru))`.

## Правила для текстов

- Русский — первым аргументом, узбекский — вторым. Интерполяции (`$name`,
  `${x}`, `%s`) — в обоих вариантах одинаковые.
- Узбекский — латиница, обращение на «siz». Кнопки — отглагольным
  существительным: *Saqlash, Bekor qilish, Oʻchirish*. Поля — повелительным:
  *Nomini kiriting, Doʻkonni tanlang*.
- Апострофы — типографские: **oʻ, gʻ** (U+02BB `ʻ`) и **ʼ** (U+02BC, «tutuq
  belgisi»: *maʼlumot, taʼminot*). ASCII `'` в узбекских строках не используем
  (в Dart ломает строку).
- После числа в узбекском существительное — в единственном числе:
  *5 ta mahsulot*, *3 kun*. Русские функции склонения (`plural(...)`)
  в узбекской ветке не нужны.
- Не переводим: комментарии, логи, коды и статусы, которые уходят на сервер,
  названия брендов, «Super Market», Telegram, Payme, Click.
- `tr()` — не `const`: у виджетов/литералов с `tr()` снимаем `const`;
  `static const` строки и карты меток превращаем в геттеры/функции.
